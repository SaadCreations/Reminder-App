# ⏰ Reminder App

A clean and responsive Reminder App built with **HTML**, **CSS**, and **JavaScript** that allows users to set, view, complete, and delete reminders with real-time browser notifications and alarm sounds.

## 📋 Description

The Reminder App helps users remember tasks and events by scheduling reminders. It stores reminders in the browser's **localStorage**, so they persist even after reloading. You get desktop notifications and an alarm sound when the time comes.

## ✨ Features

- Add new reminders with a title and time
- View all upcoming reminders
- Mark reminders as completed (or undo)
- Delete reminders
- Notifications with icons
- Alarm sound on due time
- Responsive layout for mobile and desktop
- Local storage support (reminders stay even after refresh)
- Auto-check and update reminders every minute
